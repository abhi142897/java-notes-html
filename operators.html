Bitwise Operators

Bitwise operators work at the binary (bit) level.

Java
int a = 5;   // 0101
int b = 3;   // 0011

System.out.println(a & b);  // 0001 -> 1
System.out.println(a | b);  // 0111 -> 7
System.out.println(a ^ b);  // 0110 -> 6
System.out.println(~a);     // -6

Note: ~n = -(n + 1) e.g. ~5 = -6

Bitwise Shift Operators

Shift operators move bits left or right.

OperatorNameBehavior
<<Left Shiftshift bits left
>>Signed Right Shiftpreserves sign
>>>Unsigned Right Shiftfills with 0

Left Shift <<

value << n = value * 2^n

Java
int x = 5;   // 00000101

System.out.println(x << 1);  // 5 * 2^1 = 10
System.out.println(x << 2);  // 5 * 2^2 = 20

Binary => 00000101 << 1 → 00001010

Signed Right Shift >>

value >> n = value / 2^n

Java
int x = 20;

System.out.println(x >> 1); // 10
System.out.println(x >> 2); // 5

Preserves sign bit. e.g. -8 >> 1 = -4

Unsigned Right Shift >>>

Fills leftmost bits with 0 regardless of sign.

Java
public class Test {
    public static void main(String[] args) {

        int x = -8;

        System.out.println(x >> 1);   // -4
        System.out.println(x >>> 1);  // 2147483644
    }
}

i++ vs ++i

Post Increment i++

Java
int i = 5;

int x = i++;

System.out.println(i); // 6
System.out.println(x); // 5

Pre Increment ++i

Java
int i = 5;

int x = ++i;

System.out.println(i); // 6
System.out.println(x); // 6

Common Interview Trap

Java
int i = 5;

System.out.println(i++ + ++i); // 12

Execution:

diagram
i = 5

i++  → returns 5, i becomes 6
++i  → becomes 7

5 + 7 = 12
