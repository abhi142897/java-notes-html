ThreadLocal & Virtual Threads

ThreadLocal

  • ThreadLocal is used to store data that is local to a thread, so that each thread works with its own isolated value.
  • Each thread has its own:
diagram
Thread → ThreadLocalMap → (ThreadLocal → value)
Java
public class Practice {
    private static final ThreadLocal<Integer> threadLocal =
            ThreadLocal.withInitial(() -> 0);

    public static void main(String[] args) {

        Runnable task = () -> {
            threadLocal.set((int) (Math.random() * 100));

            System.out.println(
                    Thread.currentThread().getName() +
                            " value: " + threadLocal.get()
            );

            threadLocal.remove(); // important
        };

        Thread t1 = new Thread(task);
        Thread t2 = new Thread(task);

        t1.start();
        t2.start();
    }
}

Output:

diagram
Thread-1 value: 8
Thread-0 value: 15
  • Each thread has different value ✅
  • Always do clean up ✅

Virtual Threads (java 21)

  • Used to get high throughput not latency. They are more scalable, not faster.
  • A virtual thread is a lightweight thread managed by the JVM, not the OS, designed to handle massive concurrency efficiently.
  • Key Idea
  • Instead of:

1 Thread = 1 OS Thread ❌

  • Now:

Many Virtual Threads → Few OS Threads ✅

How It Works Internally

  • JVM manages virtual threads
  • Uses a small pool of OS threads (called carrier threads)
  • Virtual threads are:
  • Mounted on carrier thread when running
  • Unmounted when waiting (e.g., I/O)
  • Thread.sleep(1000);
  • Platform thread: Blocks OS thread ❌
  • Virtual thread: Releases carrier thread ✅
Java
public class Practice {
    public static void main(String[] args) {

        try (ExecutorService executor =
                     Executors.newVirtualThreadPerTaskExecutor()) {

            for (int i = 0; i < 1000; i++) {
                executor.submit(() -> {
                    System.out.println("Running in: " + Thread.currentThread());
                });
            }
        }
    }
}
