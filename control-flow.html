Control Flow

Modern Switch (Java 12+)

  • Switch Expressions
  • Arrow syntax (->)
  • Multiple case labels
  • No fall-through behavior
Java
int day = 3;

String result = switch(day) {
    case 1, 2, 3 -> "Start of week";
    case 4, 5 -> "Mid week";
    case 6, 7 -> "Weekend";
    default -> "Invalid";
};

yield in Switch (Java 13+)

Used to return a value from a block inside switch expression.

Java
int num = 5;

String result = switch(num) {
    case 1 -> "One";
    case 5 -> {
        System.out.println("Five detected");
        yield "Five";
    }
    default -> "Other";
};

yield replaces break value concept.

Pattern Matching for Switch (Java 21)

Modern control flow using type patterns.

Java
Object obj = "Hello";

switch(obj) {
    case String s -> System.out.println("String: " + s);
    case Integer i -> System.out.println("Integer: " + i);
    default -> System.out.println("Other");
}

Removes many instanceof checks.

Static Block Control Flow

  • Execution order during class loading.
  • Order:
  • Static variables
  • Static blocks
  • Static methods (when called)
Java
class Test {
    static int a = 10;

    static {
        System.out.println("Static block executed");
    }
}
  • Runs once when class loads.

Instance Initialization Block

Runs every time object is created, before constructor.

Java
class Test {

    {
        System.out.println("Instance block");

    Test(){

    }
}

Order of Execution

When object is created:

  1. Static variables
  2. Static blocks
  3. Main method
  4. Instance variables
  5. Instance block
  6. Constructor

Example:

Java
// This class demonstrates the order of execution of static blocks, instance blocks, constructors, and the main method in Java.
public class Employee {
    static int age;
    String name;
    static{
        System.out.println("Static block executed");
    }
    {
        System.out.println("Instance block executed");
    }

    public static void main(String[] args) {
        System.out.println("Main method executed");
    }
    public Employee() {
        System.out.println("Constructor executed");
    }
}

// Usage
public class Main {
    public static void main(String[] args) {
        Employee employee = new Employee();
        System.out.println("Employee object created");
    }
}

Output:

diagram
Static block executed
Instance block executed
Constructor executed
Employee object created

break vs continue

  • break immediately terminates the loop and control moves to the statement after the loop.
  • continue skips the current iteration and jumps to the next iteration of the loop.
Java
for(int i = 1; i <= 10; i++) {

    if(i == 3)
        continue;

    if(i == 7)
        break;

    System.out.println(i);
}

Output:

diagram
1
2
4
5
6

Labeled break (Advanced)

Used to break outer loops.

Java
outer:
for(int i = 1; i <= 3; i++) {

    for(int j = 1; j <= 3; j++) {

        if(j == 2)
            break outer;

        System.out.println(i + " " + j);
    }
}
  • break outer exits both loops immediately.
  • Otherwise, in case of nested loops it will only break inner loop and outer loop will continue to iterate.
